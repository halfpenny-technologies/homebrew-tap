# VibeCodeStorage Homebrew tap

```sh
brew install pauldodd123/tap/vibecodestorage
vibecodestorage --help
vibecodestorage init --endpoint https://YOUR_API_HOST --json
```

Client-only SDK and CLI release. No server source is included. No public default
API is connected yet: supply your own running API endpoint (localhost is allowed).
Requires Node 24, installed by the formula. Billing is disabled in the prototype.
